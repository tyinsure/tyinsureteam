# Check Point 5 Update — ปุ่มเลือกมุมมองเบี้ยชำระ

วันที่ 23 ตุลาคม 2026 ต่อจาก `checkpoint-5-update-1`

- ปุ่มเฉพาะงวดที่เลือก แสดงเบี้ยต่องวดตามตัวเลือกปัจจุบัน
- ปุ่มทุกงวดชำระ เทียบรายปี ราย 6 เดือน ราย 3 เดือน และรายเดือนในกล่องเดียว
- คงทุนประกันและสัญญาเพิ่มเติมเหมือนกันทุกคอลัมน์ ใช้อัตราของแต่ละงวดโดยตรง
- คำนวณจากเบี้ยประกันก็ยังเปรียบเทียบทุนที่คำนวณได้ชุดเดิม ไม่ตีความจำนวนเบี้ยเป็นเบี้ยของงวดอื่น
- แสดงยอดรวมสัญญาเพิ่มเติมและเบี้ยรวมปีแรกครบทุกงวด
- ไม่เปลี่ยนงวดชำระสำหรับตารางรายปี PDF และ Excel เมื่อกดปุ่มเลือกมุมมอง
- รองรับหน้าจอเล็กด้วยพื้นที่ตารางเลื่อนแนวนอนภายในกล่อง
- ชุดทดสอบ 26 ชุด รวมการสลับปุ่ม การเปรียบเทียบทั้งสองวิธีคำนวณ และการคงค่าเมื่อสลับมุมมอง
