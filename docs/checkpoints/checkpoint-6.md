# Check Point 6 — แผนมรดกและวัยเก๋าคุ้มได้ใจ

วันที่ 23 ตุลาคม 2026 (Asia/Bangkok)

บันทึกหลังนำกล่อง “ความคุ้มครองของแผนที่เลือก” ออกจากหน้าวัยเก๋าตามคำขอ โดยนำ markup และตัวอ้างอิง DOM ของกล่องออกจากทั้งเส้นทางคำนวณสำเร็จและเส้นทางข้อมูลผิด

## สถานะงานที่เก็บไว้

- หน้าแผนมรดกมีตัวเลือกสัญญาหลักในกล่องออกแบบแผน รองรับ 99/20 และวัยเก๋าคุ้มได้ใจ 99/10
- 99/20 เลือก PA อัตโนมัติและปิด Checkbox ไม่ได้ เปลี่ยนแผน PA ได้ ตารางแสดงเบี้ยรวมเฉพาะปี
- วัยเก๋าเลือกทุนด้วยปุ่ม 100,000 / 200,000 / 300,000 / 500,000 บาท รองรับรายปีและรายเดือนตามตารางต้นฉบับ
- ทุนวัยเก๋า 500,000 บาท เลือกอุบัติเหตุแผน 4 หรือ 5 ได้ วงเงินชดเชยจำกัดตามแผน
- สุขภาพวงเงินแน่นอนรายเดือน = รายปี × 0.09 ปัดเต็มบาทแบบครึ่งขึ้นก่อนรวม 12 งวด ครอบคลุมอัตราต่ออายุถึง 89 ปี
- ส่วนเบี้ยชีวิตสำหรับภาษี กรณีรายเดือน = ส่วนเบี้ยชีวิตรายปี × 0.09 × 12
- ตารางวัยเก๋ารวมเบี้ยอุบัติเหตุและชดเชยเป็น “เบี้ยสัญญาเพิ่มเติม” ไม่มีคอลัมน์เบี้ยหลักสะสมหรืออุบัติเหตุสาธารณะ ใช้หัวข้อ “กรณีเสียชีวิต” และ “กรณีเสียชีวิตจากอุบัติเหตุ”
- PDF วัยเก๋ามีเฉพาะตารางเบี้ยประกันและตารางผลประโยชน์ ไม่มีหน้าสรุปความคุ้มครองและหน้าเงื่อนไขแยก
- หมายเหตุสุขภาพวงเงินแน่นอนแสดงเมื่อเลือกสัญญานี้เท่านั้น ทั้งในระบบและไฟล์ส่งออก โดยแยกข้อความเป็น 3 บรรทัดตามที่ระบุ
- สูตรความคุ้มครองและข้อมูลที่ใช้คำนวณยังเก็บไว้ การลบกล่องเป็นการนำออกจากหน้าจอ

## ผลตรวจ ณ จุดบันทึก

- ชุดทดสอบ 28/28 ชุดผ่าน
- ตรวจ local references 90 จุด และ HTML IDs ไม่ซ้ำ
- ทดสอบเบราว์เซอร์จริง: ไม่มีกล่องที่ลบ การเลือกชดเชยและรายเดือนคำนวณได้ กรอกอายุผิดปิดการส่งออกและกลับมาใช้งานได้หลังแก้ค่า ไม่พบ JavaScript error ในขั้นตอนที่ทดสอบ
- ผ่านการตรวจ PDF ทั้งกรณีเลือกและไม่เลือกสุขภาพวงเงินแน่นอนในการแก้ไขก่อนหน้าจุดบันทึกนี้
