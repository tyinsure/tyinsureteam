# OPD เหมาจ่าย — supplied source mapping

Added to the Health page after the Health selector, before daily compensation. OPD ต่อครั้ง was subsequently enabled from its own supplied benefit and modal-rate tables; see `per-visit/README.md`. Each product retains its own age limits, pricing and terms.

- `source-1.png`: 11 annual age bands, six yearly benefit limits (15,000 / 20,000 / 25,000 / 30,000 / 50,000 / 100,000 baht), male/female rates, occupation classes 1 and 2. All 132 annual table cells are transcribed in `dist/opd-maochai.mjs`. Table ages are 6–98; 91–98 are explicitly renewal-only. New quotes therefore use the available non-renewal table ages 6–90, subject to the underlying policy's own age limits. This is a pricing-table boundary, not a statement that underwriting acceptance is guaranteed.
- `source-2.png`: six-month factor 0.52, quarterly 0.26, monthly 0.087, applied to the annual premium after any applicable annual discount. No discount rate was supplied, so the supplied annual table is used directly. All premiums use whole baht. User explicitly confirmed on 2026-10-24 that .50 rounds up. Integer arithmetic implements this without floating-point tie errors. Annual schedule totals use the rounded selected instalment premium times the number of payments.
- `source-3.png`: yearly OPD benefit limit, consultations (general/specialist), physiotherapy, occupational therapy, diagnostic/laboratory tests, X-rays, ultrasound and medicines; maximum two visits per day; medicines no more than 30 days following outpatient treatment.
- `source-4.png`: waiting periods of 30, 120 and 180 days; specified condition lists; start/reinstatement/increased-benefit timing and exceptions for qualifying emergency accidents. Summarised in OPD_TERMS and included in the UI, LINE text, PDF and Excel.

The selected OPD premium is included in the existing premium card, all-payment comparison, yearly/modal schedule and export totals. Main benefits and accumulated main premiums do not change. Renewals use attained-age OPD rates through 98, with no OPD premium on the main maturity row at 99. OPD does not substitute for PA/Care Plus/CI where a main policy specifically requires those riders; it does count toward the existing total additional-premium requirement on the fixed-50,000 whole-life policy.

PDF: selected OPD terms and benefit limit appear on an additional portrait A4 page only when OPD is selected. Excel retains annual premiums and includes the selected OPD benefit/terms. Turning OPD off removes it from costs, summaries, tables and export details.

Verification: 4,464 age/sex/benefit/payment lookups, direct source anchors, half-up ties, entry/renewal boundaries, 48 combinations with all existing riders, modal comparison, unchanged main benefits, main-policy eligibility, UI removal and invalid-age recovery; actual PDF/Excel downloads reopened and visually checked.
